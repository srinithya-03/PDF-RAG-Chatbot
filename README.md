# PDF Question Answering Chatbot

## Project Overview
The PDF Question Answering Chatbot is an AI-powered application that allows users to upload PDF documents and ask questions based on their content. It uses Large Language Models (LLMs) and Retrieval-Augmented Generation (RAG) to provide relevant answers.

## Features
- Upload PDF documents.
- Extract text from PDF files.
- Process and retrieve relevant information.
- Ask questions based on PDF content.
- Generate AI-powered answers.
- Interactive user interface.

## Technologies Used
- Python
- Streamlit
- LangChain
- FAISS
- Sentence Transformers
- Retrieval-Augmented Generation (RAG)

## Installation

Install the required libraries:

`pip install -r requirements.txt`

## Run the Application

`streamlit run app.py`
